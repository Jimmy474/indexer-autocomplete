Detects unresolved or malformed library index references in Markdown files.

This inspection parses custom macro syntax and validates the fully qualified names against the project's generated JSON library index. It highlights missing packages, unresolved classes, non-existent methods or fields, and structural syntax errors (such as trailing member prefixes).

When an unresolved reference or typo is detected, the inspection provides quick fixes to automatically correct the class, package, or member name based on the closest available match in the index.

Incorrect code: 



Check out the @`com.example.TypoClass` utility.

    
Call @`com.example.MathUtil#calculte` to compute the value.

    
See the @`com.example.MathUtil#` documentation.`

Correct code: 


Check out the @`com.example.ActualClass` utility.

Call @`com.example.MathUtil#calculate` to compute the value.

See the @`com.example.MathUtil` documentation.

Note: This inspection requires the library-index-dependency directory to be present in the project root containing the generated JSON metadata. If this directory is missing, the inspection will flag the elements with a project-wide warning.
