Validates and resolves custom Library Index references.

This inspection ensures that your custom @`...` syntax correctly resolves to existing classes, methods, and fields within the project and attached libraries.

Syntax Reference

The general format for a library reference is:

@`[ClassFQN][#member][(parameters)][flags]`
1. Targeting Symbols
  • Class: @`java.lang.String`
  • Field: @`java.lang.System#out`
  • Method (Any overload): @`java.lang.String#substring`
  • Method (Specific overload): @`java.lang.String#substring(int,int)`
2. Formatting Flags

Append these flags at the end of the reference to change how it is displayed:

  • - Short Name: Displays only the simple name (e.g., String).
  • + Full Name: Displays the fully qualified name (e.g., java.lang.String).
  • | Custom Name: Overrides the display text entirely. Example: @`java.lang.String|My Custom Text`
3. Method-Specific Flags

When referencing methods, use these flags to format the parameter output:

  • : Type Only: Displays parameter types.
  • , Name Only: Displays parameter names.
  • ; Both: Displays both types and names.
  • ^ Return Type: Displays the method's return type.

Examples

  • @`java.util.List#add(java.lang.Object)-` → Resolves to add(Object) and renders short names.
  • @`java.util.Collections#emptyList|Get Empty List` → Resolves to the method and renders as "Get Empty List".
